## Running & Evaluation Environment
This repository is tested and evaluated under the environment specified below. All regression testing and coverage collection experiments rely on the following software versions.

### Basic Environment
- OS: Ubuntu 22.04
- C Compiler: GCC 11.2.1 (for compiling database source code)
- Code Coverage Tool: lcov 1.16 (for calculating line coverage)

### Database Kernels
- PostgreSQL 13.23
- SQLite 3.53.1
